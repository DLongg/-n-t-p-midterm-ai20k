CÂU 09 [TÍNH TOÁN / ĐIỀN SỐ CHÍNH XÁC] - Mã: d15-q027 (Độ khó: medium)
========================================================================
ĐỀ BÀI:
Bối cảnh:
Cùng một tháng: hosted API $4.000; logging/storage $500; human review $1.200. Self-hosted GPU lease $3.000; utilization overhead $600; ops labor $2.000; logging/storage $500.

Câu hỏi:
Tính chênh lệch TCO self-hosted trừ hosted.

-> ĐÁP ÁN SỐ CHÍNH XÁC: 400 USD/tháng

LỜI GIẢI THÍCH CHI TIẾT TỪ VLEARN:
      Hosted TCO: $4.000 + $500 + $1.200 = $5.700. Self-hosted TCO: $3.000 + $600 + $2.000 + $500 = $6.100. Chênh lệch TCO self-hosted trừ hosted: $6.100 - $5.700 = 400 USD/tháng.
CÂU 10 [TÍNH TOÁN / ĐIỀN SỐ CHÍNH XÁC] - Mã: d15-q030 (Độ khó: hard)
========================================================================
ĐỀ BÀI:
Bối cảnh:
Hosted có fixed $500/tháng + $0,04/request. Self-hosted có fixed $4.500/tháng + $0,004/request. Bỏ qua cost khác và cho volume liên tục.

Câu hỏi:
Tính break-even request/tháng.

-> ĐÁP ÁN SỐ CHÍNH XÁC: 111111 request/tháng

LỜI GIẢI THÍCH CHI TIẾT TỪ VLEARN:
      Break-even volume: 500 + 0,04*N = 4500 + 0,004*N => 0,036*N = 4000 => N = 4000 / 0,036 ≈ 111.111 requests/tháng.

CÂU 13 [TÍNH TOÁN / ĐIỀN SỐ CHÍNH XÁC] - Mã: d15-q036 (Độ khó: medium)
========================================================================
ĐỀ BÀI:
Bối cảnh:
Mỗi request dùng 1.000 input token giá $2/million và 200 output token giá $10/million. Có 50.000 request/ngày trong 30 ngày; bỏ qua cost khác.

Câu hỏi:
Tính monthly API subtotal.

-> ĐÁP ÁN SỐ CHÍNH XÁC: 6000 USD/tháng

LỜI GIẢI THÍCH CHI TIẾT TỪ VLEARN:
      Mỗi request: 1.000 input tokens * $2/M + 200 output tokens * $10/M = $0,002 + $0,002 = $0,004/request. Hàng tháng có 50.000 * 30 = 1.500.000 requests => Tổng chi phí: 1.500.000 * $0,004 = 6.000 USD/tháng.
