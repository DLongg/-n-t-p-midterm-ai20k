PHÂN TÍCH LỜI GIẢI / NGUYÊN LÝ THIẾT KẾ TỪ VLEARN:
      Độ tương đồng cosine: cos(θ) = (a · b) / (||a|| × ||b||). Với a = [1, 2] và b = [2, 0]: a · b = 1×2 + 2×0 = 2; ||a|| = √(1² + 2²) = √5 ≈ 2,23607; ||b|| = √(2² + 0²) = 2. Do đó cos(θ) = 2 / (√5 × 2) = 1 / √5 ≈ 0,4472136. Làm tròn ba chữ số thập phân là 0,447.

Chủ đề kiến thức (KC): [kc-euclidean-distance-computation] Euclidean Distance Computation
=====================================================================================
ĐỀ BÀI:
`u=[-1,2,4]`, `v=[2,-2,4]`. Cách tính khoảng cách Euclidean nào đúng?

CÁC PHƯƠNG ÁN LỰA CHỌN / CẶP GHÉP / BƯỚC SẮP XẾP:
[A] Cộng các chênh lệch: -3 + 4 + 0 = 1.
[B] Tính √((-3)² + 4² + 0²) = 5.
[C] Tính dot product rồi chia cho hai norm.
[D] Chỉ so chiều có chênh lệch lớn nhất nên khoảng cách = 4.

ĐÁP ÁN ĐÚNG & HƯỚNG DẪN:
👉 Hướng dẫn đáp án: Dựa trên gợi ý 'Dấu của chênh lệch mất đi sau bước bình phương.', chọn phương án phù hợp nhất.

PHÂN TÍCH LỜI GIẢI / NGUYÊN LÝ THIẾT KẾ TỪ VLEARN:
      Khoảng cách Euclidean giữa u = [-1, 2, 4] và v = [2, -2, 4]: d(u, v) = √((2 - (-1))² + (-2 - 2)² + (4 - 4)²) = √(3² + (-4)² + 0²) = √(9 + 16 + 0) = √25 = 5.

=====================================================================================
ĐỀ BÀI:
mức liên quan top-3 là `[2,0,1]`; top-3 lý tưởng là `[2,1,0]`. Dùng `DCG=Σ(2^rel−1)/log2(rank+1)`, nhập NDCG@3 làm tròn ba chữ số.

ĐÁP ÁN ĐÚNG & HƯỚNG DẪN:
👉 Hướng dẫn tính toán: Thực hiện phép tính theo công thức với đơn vị yêu cầu: 

PHÂN TÍCH LỜI GIẢI / NGUYÊN LÝ THIẾT KẾ TỪ VLEARN:
      Tính DCG@3 thực tế cho mức liên quan [2, 0, 1]: rank 1 = (2² - 1)/log₂(1+1) = 3/1 = 3; rank 2 = (2⁰ - 1)/log₂(2+1) = 0; rank 3 = (2¹ - 1)/log₂(3+1) = 1/2 = 0,5 => DCG@3 = 3 + 0 + 0,5 = 3,5. Xếp hạng lý tưởng [2, 1, 0]: rank 1 = 3; rank 2 = (2¹ - 1)/log₂(3) = 1/log₂(3) ≈ 0,6309298; rank 3 = 0 => IDCG@3 = 3 + 0,6309298 ≈ 3,6309298. NDCG@3 = DCG / IDCG = 3,5 / 3,6309298 ≈ 0,96394... Làm tròn ba chữ số thập phân là 0,964.
